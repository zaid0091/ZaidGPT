User: How does memory management work in Rust without a garbage collector?
Assistant: Rust enforces memory safety at compile-time through its Borrow Checker and Ownership system with three fundamental rules:
1. Each value in Rust has an owner variable.
2. There can only be one owner at a time.
3. When the owner goes out of scope, the value is automatically dropped and deallocated.
Borrowing allows references: either multiple immutable references (&T) OR exactly one mutable reference (&mut T) at any given time, preventing data races.

User: How do JWT (JSON Web Tokens) work for authentication?
Assistant: A JWT consists of three base64url-encoded parts separated by dots: Header.Payload.Signature.
- Header: Algorithm and token type.
- Payload: User claims (user_id, expiration, role).
- Signature: Cryptographic hash HMACSHA256(header + "." + payload, secret_key) verifying the token has not been tampered with.
Stateless: The server does not need to store session state in a database to authenticate requests.

User: How do you write a binary search algorithm in Python?
Assistant: Binary search finds the position of a target value within a sorted array in O(log n) time. Here is the implementation:

def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

User: Explain Object-Oriented Programming (OOP).
Assistant: Object-Oriented Programming organizes software around data (objects) rather than functions. Its four foundational pillars are:
1. Encapsulation: Bundling data and methods that operate on that data within a class while restricting direct access.
2. Abstraction: Hiding complex implementation details and exposing only essential interfaces.
3. Inheritance: Allowing a class to inherit attributes and methods from a parent class.
4. Polymorphism: Enabling different classes to be treated as instances of the same class through a common interface.

User: What is gravity?
Assistant: Gravity is a fundamental physical interaction by which all matter and energy are attracted toward one another. In classical physics, Newton described gravity as a force proportional to mass and inversely proportional to the square of distance. In Einstein's General Relativity, gravity is the curvature of spacetime caused by mass and energy.

User: What is the theory of relativity?
Assistant: Albert Einstein formulated two theories of relativity:
1. Special Relativity (1905): States that the laws of physics are identical in all inertial reference frames and that the speed of light in a vacuum (c ~ 300,000 km/s) is constant for all observers. It established the equivalence of mass and energy: E = mc^2.
2. General Relativity (1915): Describes gravity as the geometric curvature of 4-dimensional spacetime caused by mass and energy.

User: What are the laws of thermodynamics?

- First Law: Energy cannot be created or destroyed, only transformed (Conservation of Energy).

- Third Law: As the temperature of a system approaches absolute zero (0 Kelvin), entropy approaches a constant minimum.
