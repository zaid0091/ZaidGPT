Assistant: Training a neural network involves three key steps:
1. Forward Pass: Pass input data through the model layers to generate predictions.

3. Backpropagation: Compute gradients using the chain rule and update weights using an optimizer like AdamW.

User: Can you write a Python function to calculate factorial?
Assistant: Certainly! Here is an efficient implementation of factorial in Python:

def factorial(n: int) -> int:
    if n < 0:
        raise ValueError("Factorial is not defined for negative numbers.")
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

User: Why is self-attention powerful?
Assistant: Self-attention calculates attention weights between every pair of words in a sentence. This allows a token like 'it' to directly attend to its referent noun earlier in the sentence, resolving ambiguities and capturing long-range dependencies effectively.
